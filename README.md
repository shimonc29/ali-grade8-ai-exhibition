# תערוכת AI — כיתה ח׳, בית ספר עלי

אתר סטטי להצגת עבודות התלמידים, כולל 15 פרויקטים של 11 תלמידים.

## פריסה

העלו את **כל תוכן התיקייה** לשורש Repository ב-GitHub, ייבאו את המאגר ל-Vercel ובחרו Framework Preset: **Other**, Root Directory: `./`, ללא Build Command. לאחר פרסום ניתן יהיה להוסיף פרויקטים באמצעות קובץ HTML נוסף בתיקיית `projects/` ורשומה תואמת ב-`projects.json`.

## קבצים

- `index.html` — עמוד התערוכה
- `styles.css` — עיצוב רספונסיבי
- `app.js` — חיפוש, סינון, והצגת עבודות
- `projects.json` — רשימת העבודות, התלמידים והתיאורים
- `projects/work-XX.html` — קובצי התלמידים המקוריים, ללא שינוי

## הערות

- בפרויקט **ארץ המעיינות** של אליה גרינוולד יש הפניות לקובצי תמונה `image_*.jpg` שלא צורפו. יש להעלות אותם בהמשך אל `projects/` עם השמות המקוריים כדי שהתמונות יופיעו.
- חלק מהפרויקטים טוענים ספריות חיצוניות וזקוקים לחיבור לאינטרנט.
- ייתכנו שימושים בקוד דוגמה או נתוני דמה בפרויקטים; הם מוצגים כפי שנמסרו, ללא אימות נתונים חיצוניים.
- לפני פרסום פומבי של שמות קטינים ויצירותיהם יש לוודא שיש אישור מתאים של בית הספר/ההורים.
